# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

The portfolio serves the full public readership of the blog, including people interested in software development, financial tools, and the overlap between technology and finance. It is intended for a broad community rather than a single professional audience.

## Product Purpose

This is a public portfolio and publishing home for a developer focused on financial tools. It presents that professional focus and supports ongoing writing about technology, software development, and finance for a large community of readers.

## Positioning

The portfolio connects hands-on software development with financial-tool expertise and writing that can serve both technical and finance-oriented readers.

## Operating Context

Visitors encounter the work through a public blog and may arrive with substantially different levels of technical and financial knowledge. Content must remain useful across those audience boundaries without assuming that every reader shares the same expertise.

## Capabilities and Constraints

- Publish public writing centered on technology, software development, and finance.
- Present the author's identity as a developer specializing in financial tools.
- Serve a broad public community, including both developer and financial audiences.
- Lead visitors toward the author’s work through the primary action “Explore my work.”
- Present a real 13-week GitHub contribution calendar from authenticated GraphQL data, including anonymous private contribution counts, while keeping repository-level event detail public-only.
- Present Savyy as the sole featured project and direct visitors to its public product site.
- Provide direct contact routes through LinkedIn, X, GitHub, and email.

## Evidence on Hand

The authenticated GitHub contribution calendar for `marcm8793`, the public GitHub event feed, the existing public portfolio at `marcmansour.dev`, the public résumé, and Savyy’s published `llms.txt` provide confirmed evidence. The homepage features Savyy alone: a personal-finance application for France and Europe with 4,000+ bank coverage through PSD2 open banking, privacy-first AI categorization, and web, iOS, and Android applications. GitHub contribution totals are always read from the API and private repository identities are never exposed. The page also links to the verified LinkedIn, X, GitHub, résumé, and email destinations. It must not fabricate performance metrics, clients, testimonials, awards, or project outcomes.

## Product Principles

- Bridge software development and finance without treating either audience as an afterthought.
- Make specialized ideas legible to a broad public readership.
- Establish credibility through real work and useful writing, never invented proof.
- Prefer one substantial, source-backed project case over a shallow list of unrelated repositories.
- Support an enduring publishing practice rather than a one-time portfolio snapshot.
